# <项目名> 候选池

> 四档：**进行中**（已开分支、改了代码，还没提 PR）→ **待提**（证据齐，等用户同意）→ **待验证**（有线索，缺关键事实）→ **已筛掉**（见 excluded.md）。
> **类型只用五类**：`fix` / `test` / `feat` / `perf` / `docs`。写不出类型说明候选还没想清。
> **在审 ≥3 条时不要再往这里加新候选**（同一项目最多 3 条 open PR，硬规则 13）：只跟进已有 PR，等名额空出来。
